基類更快，接口更輕。Base class for speed. Interface for control.

WorkflowActionBase

[WorkflowAction(...)]
public sealed class GreetingAction
    : WorkflowActionBase

輸入、輸出和普通屬性由標註描述，Designer 可自動建立基礎面板。Attributes describe inputs, outputs and properties; Designer can build the generic panel.

IWorkflowActionHandler

public sealed class PingActionHandler
    : IWorkflowActionHandler

最小執行契約。定義由插件註冊時提供，適合零參數或自行管理描述的 Action。The smallest execution contract. Definition is supplied during registration.

DECISION大多數業務 Action 從基類開始；只有明確需要時才直接實作接口。Start most business Actions with the base class; use the interface when the trade-off is deliberate.
